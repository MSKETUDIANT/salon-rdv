# web : site client de salon-rdv

Site Next.js où les clients réservent (prestation, créneau, confirmation)
et gèrent leurs réservations.

Installation, variables d'environnement, tests et déploiement : voir le
README à la racine du dépôt (`../README.md`).

## Commandes (dans `web/`)

- `npm run dev` : site en local, http://localhost:3000
- `npm run lint`, `npm test`, `npm run build`
- `npm run test:e2e` : bout en bout sur la base locale (`supabase start`)
- `npm run verifier:bnf` : vérification des besoins non fonctionnels
